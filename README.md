# ناقش

منصة نقاش بغرف نصية وصوتية. خادم Node.js مع قاعدة بيانات SQLite وتسجيل دخول بالبريد.

## التشغيل على جهازك
```
npm install
JWT_SECRET=اكتب-نصاً-عشوائياً-طويلاً npm start
```
ثم افتح http://localhost:3000. الميكروفون يعمل على localhost وعلى أي موقع https.

## الأدمن
أول حساب تسجّله يصبح الأدمن. لتحديد بريد معيّن اضبط ADMIN_EMAIL، فيصبح صاحب هذا البريد أدمن عند دخوله.

## متغيرات البيئة
- JWT_SECRET: مطلوب عند النشر. نص عشوائي طويل وسرّي.
- ADMIN_EMAIL: اختياري، بريد الأدمن.
- DB_PATH: مسار ملف قاعدة البيانات. على الاستضافة اجعله داخل قرص دائم مثل /data/nashed.db، وإلا تضيع البيانات عند كل إعادة تشغيل.
- PORT: تضبطه الاستضافة غالباً.

## النشر (Render أو Railway أو Fly.io)
1. ارفع المجلد إلى مستودع GitHub.
2. أنشئ خدمة Node: أمر البناء `npm install` وأمر التشغيل `npm start`.
3. أضف المتغيرات أعلاه، وأضف قرصاً دائماً (Persistent Disk / Volume) واضبط DB_PATH عليه.
4. افتح رابط الموقع (https تلقائي)، وسجّل حسابك الأول.

## ملاحظات
- الصوت يعمل بين المتصفحات مباشرة (WebRTC) ويصلح لغرف صغيرة، من 2 إلى 6 أشخاص تقريباً. بعض الشبكات تحتاج خادم TURN كي يتصل الصوت، ويُضاف لاحقاً.
- لا يوجد استرجاع لكلمة المرور بعد، ويحتاج خدمة بريد لإرسال الروابط.
